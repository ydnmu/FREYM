# Security

FREYM is in development. There is no supported production release; fixes target
the current default branch. Passing tests does not establish recording reliability
or security certification.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/ydnmu/FREYM/security/advisories/new)
when available. If that channel is unavailable, open an issue requesting a private
contact method without disclosing exploit details, recordings, credentials or
personal information. No response-time guarantee is offered.

Include the commit, operating system, affected component, impact and a minimal
reproducer using synthetic data. Keep third-party advisories separate from
confirmed FREYM defects. Production update distribution remains disabled.
